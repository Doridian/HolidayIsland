Holiday Island

A native port of the Sunflowers island resort game Holiday Island (1996), running in your browser.

1. Get the CD

This site carries no game data. You need your own copy of the CD image, which the Internet Archive has:

Holiday Island on archive.org Download the CD (.iso, 210 MB)

It's the German CD, but every text comes from the port itself, so it plays fully in English too. Only the speech and the films' sound stay German.

2. Get a SoundFont (optional)

The music is MIDI and needs a SoundFont, which the game doesn't ship. Without one the music is silent. GeneralUser GS sounds close to the Roland Sound Canvas the music was written on:

Download GeneralUser GS (.sf2)

3. Play

  1. Open the game and choose the .iso (and the .sf2, if you have one).
  2. Press Start. The game reads the files in your browser; nothing is uploaded anywhere.

The browser keeps the files, so you only do this once per browser.

Play in English Auf Deutsch spielen

About

Holiday Island is a decompilation and native port to Rust, for Linux, Windows, macOS and the web. The source is on GitHub; its browser notes list the page's options, such as network games.

Saved games and settings stay in this browser's storage.

An unofficial port of the 1996 Sunflowers game. The game data is not included.
